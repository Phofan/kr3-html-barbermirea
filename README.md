## Краткое описание проекта
Многостраничный веб-интерфейс мужского барбершопа **barbermirea**, разработанный с использованием CSS-фреймворка **Bootstrap 5**. Сайт объединяет презентацию барбершопа, каталог стрижек и мужской косметики с живыми фильтрами, страницу команды мастеров со сравнением категорий и форму онлайн-записи (на странице контактов и в модальном окне с любых страниц).

## Используемые технологии
- **HTML5** — семантическая разметка страниц (`header`, `nav`, `main`, `section`, `article`, `footer`);
- **Bootstrap 5.3.3 (CDN)** — основной CSS-фреймворк (12-колоночная сетка, адаптивные компоненты, utility-классы и JS Bundle);
- **CSS3 (`css/custom.css`)** — минимальные пользовательские уточнения (стили текстовых блоков-заглушек, плавный отклик карточек, видимый фокус с клавиатуры, кнопка «Наверх»);
- **JavaScript (`js/main.js`)** — фильтрация каталога в реальном времени, автоподстановка выбранной услуги и мастера в модальное окно, клиентская проверка форм;
- **Git и GitHub** — контроль версий и публикация через GitHub Pages.

## Самостоятельные доработки проекта
1. **Живая фильтрация каталога (`catalog.html`)** — комбинированный фильтр по поисковому запросу, категории (стрижки, борода, комплексы, косметика), максимальной стоимости и чекбоксу выгодных предложений со счётчиком найденных карточек.
2. **Умное модальное окно онлайн-записи** — при нажатии на кнопку записи у конкретной услуги или конкретного барбера выбранные значения автоматически подставляются в выпадающие списки формы внутри `#bookingModal`.
3. **Страница команды мастеров (`masters.html`)** — карточки 6 специалистов трёх грейдов с расписанием смен и сводной таблицей сравнения категорий мастеров.
4. **Доступность и навигация** — хлебные крошки (`breadcrumb`), корректные `aria-label` и `aria-current`, видимый контур `:focus-visible` и фиксированная кнопка быстрого возврата «Наверх».
